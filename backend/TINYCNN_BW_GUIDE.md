# Tiny-CNN для ЧБ изображений (цифры 1-9)

Руководство по обучению Tiny-CNN на черно-белых изображениях с цифрами 1-9.

## 📊 Требования к данным

### **Минимальные требования:**

- **50-100 изображений** синих квадратов
- **3,200-6,400 примеров цифр** (50-100 × 64 цифры)
- **350-700 примеров на каждую цифру** (1-9)

### **Рекомендуемое количество:**

- **200-500 изображений** синих квадратов
- **12,800-32,000 примеров цифр** (200-500 × 64 цифры)
- **1,400-3,500 примеров на каждую цифру** (1-9)

### **Для высокого качества:**

- **1,000-2,000 изображений** синих квадратов
- **64,000-128,000 примеров цифр** (1,000-2,000 × 64 цифры)
- **7,000-14,000 примеров на каждую цифру** (1-9)

## 🎯 Преимущества ЧБ изображений

### **Упрощения:**

- ✅ Нет проблем с цветом
- ✅ Лучший контраст
- ✅ Меньше шума
- ✅ Проще предобработка
- ✅ Быстрее обучение

### **Меньше классов:**

- ✅ 9 классов вместо 10 (нет цифры 0)
- ✅ Более сбалансированные данные
- ✅ Выше точность на меньшем датасете

## 🚀 Быстрый старт

### 1. Запуск сервера

```cmd
run_casino_backend.bat
```

### 2. Создание данных обучения

```bash
curl -X POST http://localhost:8080/api/tinycnn/create-data \
  -H "Content-Type: application/json" \
  -d '{
    "squaresDir": "uploads/squares",
    "outputDir": "uploads/training_data"
  }'
```

### 3. Обучение модели

```bash
curl -X POST http://localhost:8080/api/tinycnn/train \
  -H "Content-Type: application/json" \
  -d '{
    "epochs": 10,
    "learningRate": 0.001,
    "batchSize": 32
  }'
```

### 4. Проверка статуса

```bash
curl http://localhost:8080/api/tinycnn/status
```

## 📁 Структура данных

### **Ожидаемая структура:**

```
uploads/
├── squares/                    # Исходные изображения квадратов
│   ├── square_001.jpg
│   ├── square_002.jpg
│   └── ...
└── training_data/              # Созданные данные обучения
    ├── digit_1_square001_0.png
    ├── digit_2_square001_1.png
    ├── digit_3_square001_2.png
    └── ...
```

### **Именование файлов:**

- `digit_{цифра}_{источник}_{позиция}.png`
- Например: `digit_7_square001_15.png` - цифра 7 из квадрата 001, позиция 15

## 🔧 Настройки модели

### **Конфигурация по умолчанию:**

```json
{
  "inputSize": 28,
  "numClasses": 9,
  "learningRate": 0.001,
  "batchSize": 32,
  "epochs": 10,
  "validationSplit": 0.2
}
```

### **Рекомендуемые параметры для ЧБ:**

- **Learning Rate:** 0.001-0.003 (выше чем для цветных)
- **Batch Size:** 32-64 (больше батчи)
- **Epochs:** 10-20 (меньше эпох из-за простоты)

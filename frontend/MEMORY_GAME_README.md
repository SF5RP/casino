# Игра "Найди пару" - Помогатор

## Описание

Новая страница для помогатора с игрой "Найди пару" - это интерактивная игра-головоломка, которая помогает развивать память и логическое мышление.

## Особенности игры

### Игровое поле

- **Размер**: 10x6 ячеек (60 ячеек всего)
- **Формат**: Сетка с возможностью размещения картинок
- **Визуальная обратная связь**: Цветовая индикация состояния ячеек

### Картинки для игры

- **Количество**: 30 уникальных картинок
- **Формат**: Placeholder изображения с номерами от 1 до 30
- **Размещение**: 5 колонок по 6 рядов в правой панели

## Как играть

### 1. Начало игры

- Нажмите кнопку "Обновить" (🔄) для начала новой игры
- Игровое поле очистится, все картинки станут доступными

### 2. Размещение картинок

- **Перетаскивайте картинки** с правой панели на игровое поле
- Используйте **drag and drop** для удобного размещения
- Размещенная картинка автоматически перевернется

### 3. Игровой процесс

- Кликайте по размещенным картинкам для их переворачивания
- Игра автоматически проверяет совпадения после каждого хода
- Найденные пары подсвечиваются зеленым цветом

### 4. Подсчет очков

- **Совпадение справа**: +10 очков
- **Совпадение снизу**: +10 очков
- **Цель**: Набрать максимальное количество очков

## Технические детали

### Структура файлов

```
src/app/admin/memory-game/
└── page.tsx          # Основная страница игры
```

### Зависимости

- React 18+ с TypeScript
- Material-UI (MUI) для компонентов
- Next.js 15+ с App Router
- **react-beautiful-dnd** для drag and drop функциональности

### Состояние игры

- `gameBoard`: Массив 6x10 с ячейками
- `draggableImages`: Массив из 30 картинок
- `score`: Текущий счет
- `moves`: Количество ходов
- `selectedImage`: Выбранная для размещения картинка

### Логика проверки совпадений

- Проверка соседних ячеек справа и снизу
- Автоматическое обновление после каждого хода
- Подсветка найденных пар

## Навигация

### Кнопки управления

- **🔄 Обновить**: Начать новую игру
- **❓ Помощь**: Показать инструкции (заглушка)
- **⬅️ Назад**: Вернуться в админ-панель

### Доступ к игре

- **URL**: `/admin/memory-game`
- **Из админ-панели**: Кнопка "🎮 Игра 'Найди пару'" в верхней панели

# Memory Game - Структура компонентов

## Обзор

Игра "Найди пару" разделена на модульные компоненты для лучшей организации кода и переиспользования.

## Структура папок

```
memory-game/
├── components/           # React компоненты
│   ├── GameHeader.tsx   # Заголовок игры с кнопками управления
│   ├── GameBoard.tsx    # Игровое поле
│   ├── GameCell.tsx     # Отдельная ячейка игрового поля
│   ├── ImagePanel.tsx   # Панель с картинками для перетаскивания
│   ├── ImageItem.tsx    # Отдельный элемент изображения
│   ├── DraggingOverlay.tsx # Плавающий элемент при перетаскивании
│   ├── ImageModal.tsx   # Модальное окно выбора картинок
│   ├── TextModal.tsx    # Модальное окно выбора названий
│   └── index.ts         # Экспорт всех компонентов
├── hooks/               # Кастомные React хуки
│   ├── useMemoryGame.ts # Основной хук управления состоянием игры
│   ├── useGameActions.ts # Хук для действий с игрой
│   ├── useDragAndDrop.ts # Хук для drag and drop
│   ├── useMobileDetection.ts # Хук определения мобильного устройства
│   └── index.ts         # Экспорт всех хуков
├── types/               # TypeScript типы
│   └── index.ts         # Интерфейсы и типы для игры
├── utils/               # Утилиты
│   └── animations.ts    # Анимации для игры
├── styles.css           # CSS стили для анимаций
├── page.tsx             # Основная страница игры
└── README.md            # Этот файл
```

## Компоненты

### GameHeader

Заголовок игры с:

- Названием игры
- Кнопкой новой игры
- Переключателем типа модального окна (картинки/текст)

### GameBoard

Игровое поле с:

- Адаптивной сеткой (10x6 для мобильных, 6x10 для десктопа)
- Обработкой кликов по ячейкам
- Поддержкой drag and drop

### GameCell

Отдельная ячейка игрового поля с:

- Отображением изображения
- Анимациями для найденных пар
- Иконкой удаления
- Поддержкой перетаскивания

### ImagePanel

Панель с картинками для перетаскивания:

- Скрыта на мобильных устройствах
- Адаптивная сетка изображений
- Индикаторы использования

### ImageModal & TextModal

Модальные окна для выбора:

- ImageModal: выбор картинок
- TextModal: выбор названий (для мобильных)

### DraggingOverlay

Плавающий элемент при перетаскивании:

- Скрыт на мобильных устройствах
- Визуальная обратная связь

## Хуки

### useMemoryGame

Основной хук управления состоянием:

- Состояния игры (поле, картинки, анимации)
- Функции инициализации и проверки совпадений
- Сеттеры для всех состояний

### useGameActions

Хук для действий с игрой:

- Обработка кликов по ячейкам
- Удаление картинок
- Перемещение между ячейками
- Размещение картинок

### useDragAndDrop

Хук для drag and drop:

- Обработка перетаскивания изображений
- Поддержка touch событий
- Перетаскивание между ячейками

### useMobileDetection

Хук определения мобильного устройства:

- Анализ user agent
- Проверка touch поддержки
- Обработка изменения ориентации

## Типы

### CardItem

Интерфейс ячейки игрового поля:

- id, image, isMatched, isFlipped, isPlaced, showDeleteIcon

### DraggableImage

Интерфейс перетаскиваемого изображения:

- id, image, fallbackImage, isUsed, usageCount, maxUsage

### CellPosition

Интерфейс позиции ячейки:

- row, col

### AnimationType

Тип анимации:

- "deletion" | "celebration" | null

## Особенности

1. **Адаптивность**: Автоматическое определение мобильного устройства
2. **Touch поддержка**: Полная поддержка touch событий
3. **Анимации**: Плавные анимации для найденных пар и удаления
4. **Модульность**: Каждый компонент отвечает за свою функциональность
5. **Типизация**: Полная TypeScript типизация
6. **Производительность**: Оптимизированные хуки и компоненты

## Использование

Основная страница (`page.tsx`) использует все компоненты и хуки для создания полнофункциональной игры. Логика разделена между хуками, а UI представлен компонентами, что обеспечивает чистоту кода и легкое тестирование.

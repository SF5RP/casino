# Как переименовать изображения для игры "Найди пару"

## 🎯 Цель

Переименовать все изображения в формат: `image-1.jpg`, `image-2.jpg`, ..., `image-30.jpg`

## 📁 Текущее состояние

У вас есть HTML файлы для тестирования: `temp-1.html`, `temp-2.html`, ..., `temp-30.html`

## 🔄 Способы переименования

### Вариант 1: Автоматическое переименование (PowerShell)

1. Откройте PowerShell в папке `casino/frontend`
2. Запустите скрипт: `powershell -ExecutionPolicy Bypass -File rename-images-en.ps1`

### Вариант 2: Ручное переименование

1. Откройте папку `public/images/memory-game`
2. Переименуйте каждый файл в нужный формат
3. Убедитесь, что имена точно соответствуют: `image-1.jpg`, `image-2.jpg`, etc.

### Вариант 3: Использование HTML файлов

1. Откройте HTML файлы в браузере (например, `temp-1.html`)
2. Сохраните страницу как изображение (Ctrl+S, выберите формат JPG)
3. Переименуйте сохраненные файлы в нужный формат

## ⚠️ Важные требования

- **Формат**: `.jpg` (не `.JPG` или `.jpeg`)
- **Размер**: 150x150 пикселей (рекомендуется)
- **Количество**: ровно 30 изображений
- **Именование**: `image-1.jpg` до `image-30.jpg`

## 🎮 После переименования

1. Перезапустите сервер разработки: `yarn dev`
2. Откройте игру: `http://localhost:3000/admin/memory-game`
3. Нажмите кнопку "Обновить" для начала новой игры

## 🆘 Если что-то не работает

1. Проверьте имена файлов - должны быть точно `image-1.jpg`, `image-2.jpg`, etc.
2. Убедитесь, что файлы имеют расширение `.jpg` (строчные буквы)
3. Проверьте, что в папке ровно 30 изображений
4. Очистите кэш браузера (Ctrl+F5)
5. Перезапустите сервер разработки

## 📋 Проверка результата

После переименования в папке должно быть:

```
public/images/memory-game/
├── README.md
├── HOW_TO_RENAME.md
├── image-1.jpg
├── image-2.jpg
├── image-3.jpg
├── ...
└── image-30.jpg
```

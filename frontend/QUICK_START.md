# 🚀 Быстрый старт игры "Найди пару"

## ✅ Что уже готово:

- Игра полностью настроена и работает
- API endpoint для placeholder изображений создан
- HTML файлы для тестирования готовы
- Dev сервер запущен

## 🎮 Как начать играть:

### 1. Откройте игру в браузере:

```
http://localhost:3000/admin/memory-game
```

### 2. Нажмите кнопку "Обновить" для начала новой игры

### 3. Игра автоматически загрузит placeholder изображения

## 🖼️ Как добавить свои изображения:

### Вариант 1: Использовать существующие HTML файлы

- Откройте `temp-1.html` до `temp-30.html` в браузере
- Сохраните каждую страницу как изображение (Ctrl+S → JPG)
- Переименуйте в `image-1.jpg`, `image-2.jpg`, ..., `image-30.jpg`

### Вариант 2: Добавить свои изображения

- Поместите 30 изображений в папку `public/images/memory-game/`
- Переименуйте их в формат `image-1.jpg` до `image-30.jpg`
- Перезапустите сервер: `yarn dev`

## 🎯 Особенности игры:

- **Drag & Drop** - перетаскивайте картинки на поле
- **Двойное размещение** - каждое изображение можно поставить 2 раза
- **Бонусные очки** - диагональные пары дают +15 очков
- **Увеличенные картинки** - размер 80x80 пикселей

## 🆘 Если что-то не работает:

1. Проверьте, что сервер запущен: `yarn dev`
2. Очистите кэш браузера: Ctrl+F5
3. Проверьте консоль браузера на ошибки

# Руководство по использованию системы анализа синих квадратов

## Обзор

Система автоматически находит и анализирует синие квадраты с цифрами на загруженных изображениях. Использует компьютерное зрение для обнаружения квадратов и Tesseract OCR для распознавания цифр.

## Как использовать

### 1. Запуск системы

**Бэкенд:**

```bash
cd backend
go run ./cmd/server
```

Сервер запустится на `http://localhost:8080`

**Фронтенд:**

```bash
cd frontend
npm run dev
```

Фронтенд будет доступен на `http://localhost:3000`

### 2. Загрузка изображений

1. Перейдите на страницу `/school/math`
2. Нажмите "Выбрать файлы" или перетащите изображения в дропзону
3. Поддерживаемые форматы: JPEG, PNG, GIF, BMP, WebP (до 10MB)

### 3. Анализ результатов

После загрузки система автоматически:

- Найдет синие квадраты на изображении
- Выделит их зелеными прямоугольниками
- Распознает цифры в каждом квадрате
- Покажет результаты с уверенностью обнаружения

## Результаты анализа

### Найденные квадраты

- **Позиция**: координаты (x, y) левого верхнего угла
- **Размер**: ширина × высота в пикселях
- **Уверенность**: процент уверенности в обнаружении (0-100%)

### Распознанные цифры

- Система ищет сетку 8×8 цифр в каждом квадрате
- Поддерживаются цифры 1-9
- Результаты отображаются в виде матрицы

## Технические детали

### Алгоритм обнаружения

1. **Предобработка**: улучшение контраста и резкости
2. **Цветовая фильтрация**: поиск синих областей в HSV
3. **Морфологические операции**: очистка от шума
4. **Анализ контуров**: поиск квадратных форм
5. **Фильтрация по размеру**: отбор подходящих квадратов

### OCR процесс

1. **Обрезка**: извлечение найденного квадрата
2. **Бинаризация**: преобразование в черно-белое
3. **Сегментация**: разделение на ячейки 8×8
4. **Распознавание**: Tesseract OCR для каждой ячейки
5. **Постобработка**: очистка и валидация результатов

## Настройки

### Переменные окружения

- `TESSERACT_PATH` - путь к исполняемому файлу Tesseract
- `OCR_ROW_EXPANSION` - коэффициент расширения строк (по умолчанию 6)

### Параметры обнаружения

- Ожидаемый размер квадрата: 494px (±15%)
- Минимальная площадь: 0.6% от размера изображения
- Соотношение сторон: 0.85-1.15 (квадрат)
- Позиция: в пределах 45% от центра изображения

## Устранение неполадок

### Квадраты не найдены

- Проверьте, что квадраты действительно синие
- Убедитесь, что размер квадратов подходящий
- Попробуйте улучшить освещение на изображении

### Плохое распознавание цифр

- Убедитесь, что цифры четкие и контрастные
- Проверьте, что используется только цифры 1-9
- Попробуйте изображение с лучшим разрешением

### Ошибки сервера

- Убедитесь, что Tesseract установлен
- Проверьте логи бэкенда для подробностей
- Убедитесь, что порты 8080 и 3000 свободны

## API Endpoints

### POST /api/detect-blue-square

Загружает изображение и возвращает результаты анализа.

**Параметры:**

- `image` (multipart/form-data) - файл изображения

**Ответ:**

```json
{
  "found": true,
  "count": 1,
  "squares": [
    {
      "x": 100,
      "y": 150,
      "width": 494,
      "height": 494,
      "confidence": 0.95
    }
  ],
  "processedImage": "processed_20250102_120000_image.jpg"
}
```

## Файлы результатов

- Оригинальные изображения сохраняются в `backend/uploads/`
- Обработанные изображения с выделенными квадратами сохраняются там же
- Имена файлов содержат временные метки для уникальности
